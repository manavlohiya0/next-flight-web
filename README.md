# NextFlight Web 🏔️✨

The official marketing website, interactive demo suite, and documentation showcase for **NextFlight** — the production Next.js 15.5 multi-tenant SaaS boilerplate.

Designed with warm editorial aesthetics, high-trust craft, and dynamic visual storytelling inspired by modern luxury interfaces.

---

## 🌟 Highlights

- **3D Continuous Hyperlapse Canvas**: Scroll-driven and time-transitioning canvas rendering photorealistic Chamonix / Mont Blanc mountain terrain seamlessly evolving across 6 matched lighting phases (Dawn, Midday, Golden Afternoon, Twilight Dusk, Milky Way Night, and Emerald Aurora).
- **Universal Silky Theme Transition**: Smooth 1.4s cubic-bezier cross-fade between Warm Daylight Parchment mode and Obsidian Aurora dark mode with zero layout or contrast anomalies.
- **Interactive AI Agent Simulator**: Live testbench demonstrating autonomous agents generating database models, Better-Auth RBAC rules, Lemon Squeezy webhooks, and multi-tenant routes in real time.
- **Interactive ROI Calculator**: Real-time business savings estimator computing developer engineering hours, infrastructure cost, and payback velocity.
- **Defensive Multi-Viewport Engineering**: Verified zero anomalies across all screen dimensions (375px Mobile, 768px Tablet, 1366px Laptop, 1920px Desktop).
- **One-Click Automated Repository Claiming**: Instant GitHub webhook delivery interface for purchasing customers.

## 🚀 Quick Start

### 1. Clone the Repository
```bash
git clone https://github.com/manavlohiya0/next-flight-web.git
cd next-flight-web
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for Production
```bash
npm run build
npm run start
```

## 🛠️ Tech Stack

- **Framework**: Next.js 15.5 App Router
- **Language**: TypeScript 5.7
- **Styling**: Vanilla CSS with curated HSL editorial design tokens & zero Tailwind overhead
- **Typography**: Newsreader (Editorial Serif), Inter (Sans), JetBrains Mono (Code)
- **Animations**: HTML5 Canvas 2D render loop & Framer Motion
- **Icons**: Lucide React
- **Payments**: Lemon Squeezy integration
